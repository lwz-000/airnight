AIRNIGHT —— 怎么启动（看这一份就够了）
================================================

项目文件夹里现在有三个"双击就能用"的文件：


① 启动游戏.cmd        ← 想玩的时候双击这个
------------------------------------------------
双击之后它会自动做完这些事：

  · 重新打包网页（保证你改过的代码生效，几秒钟）
  · 启动游戏服务器（联机对战靠它）
  · 启动网页服务器（顺便把联机也一起转发过去）
  · 自动打开浏览器，直接进游戏

窗口里会打印两条链接（联机**不再需要**把它们发给朋友）：

  自己玩               http://localhost:5173/?server=localhost:5173
  同一个 WiFi 的朋友    http://192.168.x.x:5173/?server=192.168.x.x:5173（备用）

★★ 0.0.3 起，局域网联机只要一个房间号 ★★
  你点「创建房间」，大厅里会出现 6 位房间号；朋友点「加入房间」填进去就行。
  同一个 WiFi、Radmin、UU 组网都能自动找到你的机器 —— 不用再复制链接。
  实在找不到时（少数组网工具拦广播），让朋友在「设置」里手填窗口打印的那个
  IP:端口（形如 192.168.1.5:8787）。

★ 链接里那截 `?server=` 现在只剩两个用途：
  ① 手动指定服务器地址（穿透、异机联机）；
  ② 老习惯照发也能用 —— 但记得**必须带问号后面那截**，只发 http://192.168.x.x:5173
     是连不上的（不带参数时客户端会去找 8787 端口）。

★ 防火墙：首次运行 Windows 可能弹两次提示（TCP 和 UDP），都点「允许访问」。
  UDP 只用于"让朋友自动找到你的房间"，不放行也能玩，只是要手填地址。

★ 停止：点网页主界面「设置」旁边的「退出游戏」（会先问你一次），
  或者在这个黑色窗口里按 Ctrl+C，或者直接关掉窗口。
  关掉窗口不会留下后台进程，下次双击还是干净的。

★ 0.3.2 起：端口被占会自动往后顺延
  · 网页 5173 / 游戏 8787 都从默认值开始找第一个能开的（最多试 20 个），
    窗口里打印的地址用的是**真实端口**。
  · 想固定端口就带参数：启动游戏.cmd --port=6000 --game=6001
  · 双击第二次不会开第二份，只是把已经打开的页面叫回前台（`--force` 可强行再开）。

★ 想不开黑框：启动游戏.cmd --hidden
  · 控制台整个不显示，输出写进「游戏日志.txt」（不带颜色码）。
  · 发布包里玩家双击的是「启动游戏.vbs」，它就是这个模式。
  · 也可以带上：--hidden --port=6000


② 联机测试.cmd        ← 联机出问题的时候双击这个
------------------------------------------------
它会自动开 4 个假客户端、真的打一局，然后检查：

  · 配对对不对（谁打谁）
  · 战斗有没有被中途掐掉
  · 各个客户端看到的东西一致吗
  · 输了扣多少血对不对

最后会打印一行 "ALL GOOD" 或者 "PROBLEM FOUND"。
如果是 PROBLEM FOUND，把窗口里的内容截图发给我。


③ 一键验证.cmd        ← 我改完代码之后你可以双击这个
------------------------------------------------
跑全套检查：类型检查 → 数据表检查 → 全部测试 → 战斗演示。
最后要么 "ALL GOOD"，要么把报错截图给我。

樱花联机（和不在同一个网络的朋友玩）
================================================
只需要**一条隧道**，指向本机端口 **5173**（不是 8787！）。
隧道类型选 **TCP**。

★ 关键：不要用樱花给你的"节点自带域名"（比如 frp-top.com）。
  那个域名是给你连节点用的，不是给朋友访问网站用的 ——
  用它一定会遇到「域名过白」拦截或者证书错误。

正确流程：
  1. 管理面板 → 子域绑定 → 申请一个免费的 <前缀>.nyat.app 子域名
  2. 把这个子域名绑定到你的隧道
  3. 隧道设置里，自动 HTTPS 改成「自动」
  4. ★ 重启隧道（证书是启动时才加载的，不重启不生效）
  5. 等日志里出现「已从服务器为 xxx.nyat.app 加载证书」
  6. 发给朋友的链接：

       https://你的子域.nyat.app:端口/?server=你的子域.nyat.app:端口

     注意：网页地址和 server 参数是**同一个地址**。

★ 连不上时先跑这个，别靠猜（它会告诉你卡在哪一步）：

       node scripts/pnpm.mjs tunnel -- 你的子域.nyat.app:64512

  它会检查：本机服务 → 域名解析 → 端口能不能连 → **同一端口换 Host 头对照**
  → TLS 握手，最后给一句人话结论。

  ⚠️ 注意 nyat.app 的子域开了 HSTS，浏览器**强制**用 https。
     所以证书没加载好时页面是直接打不开，而不是降级成 http。

★★★ 如果体检告诉你「域名过不去」（机房按域名白名单放行）★★★

  表现：同一端口，用纯 IP 能到 frp，用你的域名就被换成
  「未备案 / 请联系机房域名过白」的拦截页。
  这是**节点机房**在按域名判断，不是你的配置错，也不是你朋友的问题 ——
  在面板里怎么改都绕不过去。能用的办法：

  ① 最快：改用纯 IP:端口，并把「自动 HTTPS」关掉
       面板 → 隧道设置 → 自动 HTTPS = 关闭 → ★ 重启隧道
       发给朋友： http://节点IP:端口/?server=节点IP:端口
       （体检脚本会把这条链接直接打出来，复制即可）
       为什么要关自动 HTTPS：证书是给域名签的，用 IP 访问会不匹配 ——
       网页也许能"继续前往"，但 WebSocket 会直接失败，
       表现就是"页面能开、一直正在重连"。

  ② 推荐：换一个【海外节点】
       海外节点不做备案/白名单过滤，nyat.app 子域就能正常用，
       只需要实名认证，不需要 ICP 备案。换完端口会变，重跑体检脚本。

  ③ 备选：换服务商，或用虚拟局域网（Tailscale / 蒲公英）
       朋友装个小客户端即可，完全没有备案问题。

★ 如果穿透一直卡住：先用同一 WiFi 的直连链接跟朋友打上
  （启动器窗口里会打印），别在穿透上耗一整晚。

如果朋友打不开，让他按 F12 看 Console 里的红色报错发给我 ——
比自己瞎试快得多。

常见问题
================================================
Q: 双击之后窗口一闪就没了？
A: 说明打包或启动失败了。窗口现在**只有出错时才会停住**，
   如果一闪而过，右键这个 .cmd →「编辑」看看是不是被我写坏了，
   或者直接告诉我。

Q: 提示「端口 5173 已经被占用了」？
A: 你多半已经开着一个游戏窗口了。看看任务栏里有没有另一个
   黑色的命令行窗口，关掉它再双击。

Q: 浏览器里一直显示"正在重连"？
A: 大概率是链接漏了 `?server=` 那截参数。用窗口里打印的完整链接。

Q: 想看清楚棋子卡面上的字？
A: 把滚轮往上滚 —— 视角会拉近（最近是默认距离的一半），
   顶栏右上的「视角 ×1.0」徽标会亮起来。拉近之后按住棋盘空白处拖动可以平移看边角
   （中键随时可拖）；点一下那个徽标就回到最远视角。
   往下滚不会比默认视角更远，所以放心滚。

Q: 想放到桌面上？
A: 右键 启动游戏.cmd →「发送到」→「桌面快捷方式」。
