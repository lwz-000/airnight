★★★ 现在最简单的方式：双击项目文件夹里的「启动游戏.cmd」★★★
    它会自动打包 + 起两个服务器 + 打开浏览器，一个窗口全搞定。
    关掉那个窗口 = 全部停止。详细说明看「启动说明.txt」。


—— 下面是手动方式（启动器出问题时才用）——

窗口 1：打包（改了代码才需要再跑一次）
    cd E:\AIRNIGHT
    node scripts/pnpm.mjs build

窗口 2：一体化服务器（网页 + 联机都在 5173 这个端口）
    cd E:\AIRNIGHT
    node scripts/pnpm.mjs static

窗口 3：游戏服务器（8787，只在本机；5173 会把联机转发过来）
    cd E:\AIRNIGHT
    node scripts/pnpm.mjs server

然后浏览器打开：http://localhost:5173/?server=localhost:5173

★ 注意：链接后面那个 ?server=... 不能省。
  不带它的话，客户端会去找浏览器里存过的旧隧道地址（你之前樱花联机填过的），
  表现就是"一直正在重连"，看起来像服务器没开。


—— 内网穿透（樱花）——

只需要一条隧道，类型选 TCP，指向本机端口 5173（不是 8787）。
★ 不要用樱花给的"节点自带域名"（frp-top.com 这种），那个不是给朋友访问用的。
  正确做法：管理面板 → 子域绑定 → 申请免费的 xxx.nyat.app 子域 → 绑到隧道
  → 隧道的「自动 HTTPS」设为「自动」→ ★ 重启隧道 → 等日志出现"加载证书"。
  发给朋友的链接：https://你的子域.nyat.app:端口/?server=你的子域.nyat.app:端口

连不上先跑体检，别靠猜：
    node scripts/pnpm.mjs tunnel -- 你的子域.nyat.app:64512

★ 如果体检说「域名过不去」（机房按域名白名单放行，只有已备案域名能过）：
  ① 最快：面板里把「自动 HTTPS」关掉 → 重启隧道 →
     改用纯 IP:端口发链接： http://节点IP:端口/?server=节点IP:端口
  ② 推荐：换一个【海外节点】（不做备案过滤，nyat.app 子域就能用）
  ③ 备选：换服务商，或用 Tailscale / 蒲公英 这类虚拟局域网
