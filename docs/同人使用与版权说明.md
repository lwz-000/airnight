## 一句话

这是一个**非盈利的《明日方舟》同人作品**，不做任何形式的商业化。
游戏里的角色形象、名字、部分音频等资产版权归**鹰角网络 / 悠星（Hypergryph / Yostar）**所有。

**代码是公开的，素材不是。** 仓库里只有代码与抓取脚本，任何人 clone 之后要自己跑一遍
`scripts/fetch-*.ts` 才能在本机得到素材——那些素材没有被提交、也不随仓库分发。

含素材的完整包**不进入仓库**。它作为 Release 附件分档发布（`-lite` 纯代码版 /
`-full` 完整版 / `-update` 增量版），同样标注非官方、非商业；
权利人提出异议时，它是最先被下架的那一级（见「自我约束」第 5 条）。

## 素材的来源链路

小人的原始形态不是图片，是 **Spine 骨骼动画**，官方素材包含
`.skel`（二进制骨骼）+ `.atlas`（图集索引）+ `.png`（图集贴图）三个文件。

本项目在构建期用无头浏览器 + `pixi-spine` 把它们**逐帧渲染成静态 PNG 序列帧**，
只把这些 PNG 放进游戏包。

**召唤物同理。** 有些召唤物在 wiki 上没有现成头像（比如维娜·维多利亚的
「黄金盟誓」明写着"无头像"），就只能从它的 Spine 模型渲染 —— 走的是同一套
`fetch-chibi.ts`，只是官方素材的目录比干员**多一层皮肤文件夹**，脚本里用
`REMOTE_OVERRIDES` 显式写死路径，不去猜。

所以：

- 游戏包里**没有** Spine 运行时，也**没有**骨骼数据；
- 包里有的只是和半身像同性质的静态图片；
- Spine 运行时只在**构建期**本机使用，不随游戏分发。

这样做的原因见 `apps/web/public/assets/chibi/README.md`。

   《明日方舟》© 鹰角网络 / 悠星，本作是非官方同人作品。
5. **权利人提出异议就下架，不需要理由。** 承诺收到通知后 **24 小时内**处理，
   不申辩、不拖延、不要求提供权利证明。下架有明确的层级：

   | 级别 | 动作 | 后果 |
   | --- | --- | --- |
   | 1 | 删某个文件 / 某组素材 | 对应角色退回占位图 |
   | 2 | 删 `apps/web/public/assets/` 整个目录 | 全部美术退回占位图，**仍可完整游玩** |
   | 3 | 删 `apps/web/public/music/` | 无 BGM，**仍可完整游玩** |

   | 5 | 归档或删除整个仓库 | 项目终止 |

   前三级都是「删目录」，游戏会退回程序化占位图并保持完整可玩，**不需要改任何代码**。
6. **不需要任何人的游戏账号。** 不读取本机《明日方舟》客户端、不索取登录凭据、
   不与官方服务器通信。

**没有任何官方发布的"同人游戏素材许可"。** 上面这套做法是社区长期形成的惯例，
它降低了被发现的风险，**但并不等于法律上的授权或豁免**。
同人作品在各地法律下的地位并不一致，权利人有权要求下架。

所以：自己玩没问题；**一旦涉及商业化、或者被权利人点名，就必须停**——
这正是上面第 5 条那个承诺的由来，不是客套话。
把代码公开在 GitHub 上，本身也不构成任何形式的授权或豁免。

## 技术上的兜底

游戏对"素材消失"这件事是**设计过的**，素材缺失不会让它崩：

```
小人序列帧  →  半身像(stand/)  →  头像(units/)  →  程序化占位卡
```

只要把 `apps/web/public/assets/` 下的素材删掉，游戏立刻退回占位图状态，
依然可以完整游玩。也就是说——如果哪天需要清理素材，删目录就够了，
不需要改任何代码。
